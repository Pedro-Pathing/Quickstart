# TurretProof

Lean 4 + Mathlib proof that the turret converges on a still target (`TurretStep.converges`).

- `TurretProof/Step.lean` is generated by `gen_step.py` from the contracts of
  `verification/java/.../TurretStep.java`, which OpenJML proves against the turret code
  (`./gradlew verifyTurret`). Do not edit it.
- `TurretProof/Convergence.lean` is the proof: the hold set is invariant, the approach from below
  either settles into it or lowers a ranking measure by a fixed amount each loop, the approach from
  above is the mirror image, and so every run ends in the hold set and stays there.

`./gradlew verifyTurretLean` regenerates `Step.lean` and runs `lake build`.
